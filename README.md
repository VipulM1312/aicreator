# AI Creator Hub

Free static starter for an AI image/video website.

## Files
- index.html
- style.css
- script.js

## Important
This is the frontend starter. Real AI generation requires a server-side AI model/API. Do not put private API keys into `script.js` or other public GitHub files.

## GitHub Pages
Repository Settings -> Pages -> Deploy from branch -> main -> / (root) -> Save.

## Ads
The `Advertisement` boxes are placeholders. Replace them with the official ad code supplied by your ad network only after your website is ready and complies with its current policies.
